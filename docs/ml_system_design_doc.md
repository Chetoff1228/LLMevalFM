# **Документ проектирования системы ML: LLMevalFM**

### **Термины и пояснения**

- **LLMevalFM** — фреймворк для оценки фактической точности LLM, который проверяет способность моделей генерировать правдивую информацию в различных контекстах.
- **Фактическая точность (Fact Accuracy)** — способность модели предоставлять верную информацию, соответствующую реальным данным.
- **Большие языковые модели (LLM)** — модели машинного обучения, обученные на больших объемах текстовых данных, предназначенные для генерации, анализа и обработки текста.
- **Чувствительные области (Sensitive Areas)** — области, которые включают информацию, требующую особого внимания из-за ее чувствительности, такие как политика, экономика и культура.
- **Модели** — алгоритмы машинного обучения, предназначенные для выполнения задач генерации текста, обработки информации и ответов на вопросы.
- **Точность (Accuracy)** — метрика, отражающая степень правильности ответов модели в тестовых заданиях.

## **1. Обзор системы**

**LLMevalFM** — это фреймворк для оценки фактической точности больших языковых моделей (LLM), предназначенный для анализа способности моделей генерировать правдивую информацию в контексте специфичных данных, включая чувствительные области, такие как политика, экономика и культура. Основная цель — улучшить точность моделей и обеспечить их надежность для решения практических задач.

## **2. Цели и задачи**

- **Оценка фактической точности LLM**: Проверка способности LLM давать правильные ответы на вопросы из реального мира.
- **Поддержка чувствительных контекстов**: Включение специфики политических и социокультурных контекстов в оценку моделей.
- **Автоматизация процесса оценки**: Использование автоматизированных инструментов для тестирования и сравнения выводов модели с реальными данными.
- **Метрики для анализа точности**: Внедрение метрик, таких как точность, полнота, F1-score, для всесторонней оценки качества моделей.

## **3. Компоненты системы**

### 3.1 **Входные данные**

- **Текстовые данные**: Запросы и утверждения, которые будут использоваться для оценки фактической точности.
- **Исторические и реальные данные**: Базы данных с проверенной и актуальной информацией, которая будет служить эталоном для сравнения с выводами моделей.

### 3.2 **Компоненты фреймворка**

- **Модуль тестирования**:
    - Автоматически генерирует запросы для тестирования LLM.
    - Сравнивает ответы модели с фактическими данными из внешних источников (базы данных, API).
    - Обрабатывает текстовые ответы и проводит их анализ на соответствие фактическим данным.

- **Модуль анализа ошибок**:
    - Детектирует и классифицирует типы ошибок (например, фактические ошибки, ошибки синтаксиса или семантики).
    - Предоставляет отчёты об ошибках с рекомендациями для улучшения модели.

- **Метрики точности**:
    - Вычисляет точность, полноту, F1-score и другие метрики, которые характеризуют фактическую точность модели.
    - Позволяет проводить сравнительный анализ различных LLM на основе этих метрик.

- **Интерфейс для настройки фреймворка**:
    - Поддержка кастомизации для различных типов запросов и данных.
    - Настройка порогов оценки и выбора метрик.

- **Интеграция с внешними источниками данных**:
    - Возможность интеграции с базами данных и API для получения актуальных данных, например, с историческими фактами, новостями или политическими событиями.

### 3.3 **Выходные данные**

- **Отчёты об оценке**:
    - Детализированные отчёты по каждому тесту, показывающие результаты оценки фактической точности модели.
    - Рекомендации для улучшения модели на основе анализа ошибок.

- **Метрики производительности**:
    - Вычисленные метрики точности, которые позволяют пользователям сравнивать различные LLM.

### 4.1 **Подход к тестированию**

1. **Генерация запросов**: Система генерирует набор запросов, основанных на реальных данных, которые используются для оценки модели.
2. **Тестирование LLM**: Модель обрабатывает запросы и возвращает ответы.
3. **Сравнение с реальными данными**: Ответы модели сравниваются с фактами из внешних источников данных.
4. **Оценка и анализ**: Результаты сравниваются с заранее установленными метками точности и оценивания.

### 4.2 **Метрики для оценки**

- **Точность (Exact Match)**: Эта метрика показывает, насколько точно ответ модели совпадает с правильным ответом. Она вычисляется как доля случаев, когда модельный ответ идентичен правильному ответу.

  Формула:
  Точность = (Количество совпадений) / (Общее количество вопросов)

- **F1-score (Completeness)**: Оценка того, насколько ответ модели охватывает все важные аспекты вопроса. Полнота может быть вычислена с использованием метрики F1, которая учитывает как точность, так и полноту, что позволяет оценить, насколько хорошо модель отвечает на заданные вопросы.

  Формула:
  F1 = 2 * (Точность * Полнота) / (Точность + Полнота)

- **Контекстная осведомленность (Context Awareness)**: Способность модели давать ответ, соответствующий специфике вопроса и контекста, особенно в тех случаях, когда вопрос может иметь несколько интерпретаций. Эта метрика может быть оценена через коэффициент Левенштейна, который измеряет расстояние между строками.

  Формула:
  Коэффициент Левенштейна = 1 - (d(a, b) / max(|a|, |b|)), где d(a, b) — расстояние Левенштейна между строками a и b.

- **Частичное совпадение (Partial Match)**: Эта метрика оценивает, насколько ответ модели схож с правильным ответом, даже если они не идентичны. Частичное совпадение может быть вычислено с использованием функции вычисления F1, учитывающей частичные совпадения.

  Формула:
  Частичное совпадение = (Количество частичных совпадений) / (Общее количество вопросов)

- **Подстрока (Is Substring)**: Оценивает, содержится ли правильный ответ как подстрока в ответе модели. Это помогает понять, насколько близки ответы модели к правильным, даже если они не идентичны.

  Формула:
  Подстрока = 1, если REAL_ANSWER содержится в MODEL_ANSWER, иначе 0.
